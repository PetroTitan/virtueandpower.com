# Ruins

Partial structures, archaeological-site photography, and other
preserved civilizational fabric where the surviving material is the
record. Vendored locally; provenance recorded here and in the typed
registry at
[`src/data/archive-images.ts`](../../../src/data/archive-images.ts).

## Archaeological sites batch (2026-08-19)

Vendored for the `/archaeology` layer. Every file was verified through
the Wikimedia Commons API for licence, author and source dimensions
before download, resized to 1600 px on the longest edge (except where
noted) and encoded as WebP.

Two rules govern this batch specifically. Where the photograph shows a
**reconstruction** rather than an ancient surface, the registry caption
says so — a reader cannot tell reinforced concrete from gypsum in a
photograph. And where the Commons file name asserts an identification
this platform treats as **disputed**, the caption does not repeat it.

- `knossos-north-entrance.webp` — The reconstructed north entrance,
  Knossos, Crete. Bronze Age palace c. 1700–1450 BCE; the columns, roof
  and fresco panel are Arthur Evans's 1920s reinforced-concrete
  reconstruction with Gilliéron copies. Photo Moonik, CC BY-SA 3.0.
  Source 4288 × 2848 → 1600 × 1063, ~262 KB.
  https://commons.wikimedia.org/wiki/File:Knossos_north_entrance,_Crete_001.JPG
- `akrotiri-excavation.webp` — Excavated streets and standing houses at
